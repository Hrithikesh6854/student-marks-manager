# Student Marks Manager

A command-line app to manage student records, built with Python and SQLite.

## Features
- Add, view, search, update, and delete students
- Automatic total, percentage, and grade calculation
- Show the class topper and failed students
- Input validation using try/except

## Tech Used
Python, SQLite

## How to Run
1. Install Python 3
2. Run: python student_marks_manager.py
